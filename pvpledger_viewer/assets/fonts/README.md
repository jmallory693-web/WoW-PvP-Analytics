# Cinzel

Unmodified variable TrueType font from the official Google Fonts distribution:
https://github.com/google/fonts/tree/main/ofl/cinzel

Downloaded from `ofl/cinzel/Cinzel[wght].ttf` on October 29, 2026 and bundled
as `Cinzel.ttf`. Copyright 2020 The Cinzel Project Authors.
The complete SIL Open Font License 1.1 is included in `OFL.txt`.
Windows registration is private to the application process; it does not
install or change system fonts. Missing/unloadable assets fall back to Georgia.
